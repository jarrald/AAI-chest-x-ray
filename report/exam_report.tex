\begin{abstract}
\noindent
Chest X-rays often contain small letters and markings that are not part of the
body, such as an \emph{R} or \emph{L} that shows which side is which. A neural
network might use these markings as a shortcut instead of actually learning to
recognise pneumonia. In this project we test whether removing them makes a
pneumonia classifier better. We used the Kaggle \emph{Chest X-Ray Images
(Pneumonia)} dataset (5{,}856 images), split it into training, validation and
test sets (80/10/10), and trained a convolutional neural network (CNN) following
Nunamaker et~al.'s research process. We then ran a controlled experiment: we
trained one model on the original images and one on a cleaned copy with the
markings removed, keeping everything else exactly the same. The cleaned dataset
did not improve test performance: it raised specificity ($+0.019$) but lowered
sensitivity by more ($-0.030$), giving slightly lower Youden's J ($-0.0115$),
accuracy ($-0.0170$) and AUC ($-0.0013$) overall. We conclude that, for this
dataset and model, removing the markings does not give a measurable benefit: the
model's decisions are driven by the lungs rather than the markings.
\end{abstract}

% =====================================================================
\section{Introduction}
\label{sec:intro}
Pneumonia is a common and serious lung infection, and the chest X-ray is one of
the most common ways to look for it. In recent years, deep learning models have
become very good at reading chest X-rays, in some cases matching doctors
\cite{rajpurkar2017chexnet}. This makes them useful as a tool to help sort
patients.

A known problem with these models is \emph{shortcut learning}. This is when a
model gets good results by using the wrong information --- something that happens
to be linked to the answer but is not the real cause \cite{geirhos2020shortcut}.
Chest X-rays are a good example. Earlier studies found that models sometimes used
hospital-specific text printed on the image \cite{zech2018confound}, or that
COVID-19 X-ray models often looked at markers and image edges instead of the
lungs \cite{degrave2021shortcut}. Our dataset has the same kind of markings: most
images have a bright \emph{R} or \emph{L} marker, and some have extra text near
the border (Figure~\ref{fig:samples}).

This leads to a clear question we can test: if we remove these markings, does the
pneumonia classifier get better? If it does, the model was partly relying on
them. If it does not, that is a sign the markings are not what the model uses. We
test this with a controlled experiment.

% =====================================================================
\section{Research Question}
\label{sec:rq}
We phrase one main question with two supporting sub-questions.

\begin{itemize}
  \item[\textbf{Q1}] Does removing non-anatomical artifacts (e.g.\ the orientation
  marker \emph{R}) from chest X-rays improve pneumonia classification
  performance?
  \item[\textbf{Q1.1}] How can the markings be detected and removed reliably and
  quickly, without damaging the lungs?
  \item[\textbf{Q1.2}] How should the strong imbalance between \textsc{normal} and
  \textsc{pneumonia} images be handled so it does not affect the comparison?
\end{itemize}

\noindent
To answer Q1 we keep \emph{every} other factor the same between two training runs
and change only one thing --- whether the images still contain the markings --- so
that any difference in test performance must come from the cleaning alone.

\section{Methods}
\label{sec:methods}
We follow Nunamaker et~al.'s multi-methodological research process
\cite{nunamaker1990}, which moves back and forth between observing the data,
building the system and running experiments. Every step from loading the data to
the final evaluation is written in code so the results can be reproduced. We also
fix the random seed everywhere (Python, NumPy and PyTorch) so the splits,
sampling and training give the same result each time.

\subsection{Data and splitting}
\label{sec:data}
We use the Kaggle \emph{Chest X-Ray Images (Pneumonia)} dataset
\cite{kermany2018,kagglecxr}, which contains 5{,}856 chest X-ray images of
children, each labelled \textsc{normal} or \textsc{pneumonia}. The original
dataset has a very small validation set (only 16 images), so we combined all the
images and split them again into 80\,\% training, 10\,\% validation and 10\,\%
test. We use the same split for both the original and the cleaned dataset, so the
two are compared on exactly the same images (Section~\ref{sec:locked}).

\subsection{Preprocessing}
\label{sec:preproc}
Before training we prepare every image in the same way. We convert it to
grayscale, pad it to a square so it is not stretched, and resize it to
$224\times224$ pixels, which is a common input size for these models
\cite{he2016resnet}. We also scale the pixel values to a fixed range. For the
training images only, we add small random changes --- slight rotation, shifting
and zooming. This is called \emph{data augmentation}, and it helps the model
generalise instead of memorising the training images \cite{shorten2019augment}.
The validation and test images are not changed in this way.

\subsection{Class imbalance}
\label{sec:imbalance}
The dataset is uneven: about 73\,\% of the images are \textsc{pneumonia} and only
27\,\% are \textsc{normal}. If we ignore this, the model can become biased towards
the larger class \cite{he2009imbalanced,krawczyk2016imbalanced}. To avoid this we
use a \emph{weighted sampler} during training, which shows the smaller class
(\textsc{normal}) more often so each training batch has a more even mix. We do
this only for training; the validation and test sets keep their natural mix so the
results reflect a realistic situation.

\subsection{Model architecture}
\label{sec:model}
We use a custom convolutional neural network (CNN) for the image classification
task. CNNs are commonly used for image classification because they can learn
visual patterns directly from image data
\cite{lecun1998gradient,krizhevsky2012imagenet}. In this project the model
consists of three convolutional blocks (Figure~\ref{fig:arch}). Each block
contains a convolutional layer, batch normalization, a ReLU activation function,
and max-pooling. Batch normalization is used to make the training more stable
\cite{ioffe2015batchnorm}.

The number of channels increases through the network from 32 to 64 and finally to
128. This means the model starts by learning simple visual patterns, such as
edges and contrast, and later combines these into more complex image features.

After the convolutional blocks, the feature map is flattened and passed through a
fully connected classifier. This classifier contains one hidden layer with 256
units, dropout to reduce overfitting \cite{srivastava2014dropout}, and a final
output layer with two classes (\textsc{normal} and \textsc{pneumonia}). In total
the model has about 25.8 million parameters.

\subsection{Detecting and removing the markings}
\label{sec:cleaning}
The markings we want to remove (the \emph{R}/\emph{L} markers and technician text)
are small, bright spots near the edge of the image, away from the lungs. We detect
them with OpenCV \cite{bradski2000opencv} using three simple checks:
\emph{(i) location} --- the spot is near the left, right or top edge (we ignore the
bottom, where the body and film strips appear); \emph{(ii) shape} --- it is about
the size and shape of a letter; and \emph{(iii) surroundings} --- it sits on a dark
background, which separates a real marker from bright body parts such as ribs.
Once a marking is found, we fill in that area using the pixels around it (a method
called \emph{inpainting} \cite{telea2004inpaint}) so no sharp edge is left behind.
This is done by a script (\texttt{create\_cleaned\_dataset.py}) that saves a full
cleaned copy of the dataset with the same folder structure.

\subsection{The controlled two-dataset experiment}
\label{sec:locked}
To answer Q1 we train two separate models: one on the original images and one on
the cleaned images. Everything else is kept exactly the same --- the model, the
settings, which images are in each split, the preprocessing, and how we choose the
decision threshold. The only difference is whether the images still contain the
markings, so any difference in the results can only come from the cleaning.

\subsection{Hyperparameter search}
\label{sec:search}
Before the main comparison we try to improve the baseline model by testing
different training settings. We use a \emph{random search}
\cite{bergstra2012random}: rather than trying every possible combination, we
randomly pick 20 settings for four parameters --- the learning rate, the dropout
rate, the weight decay and the batch size --- train a model with each, and keep
the setting that scores best on the validation set. The first trial uses our
default settings, so the search also tells us whether tuning actually found
anything better than what we started with.

\subsection{How we measure performance}
\label{sec:eval}
Accuracy on its own is not enough here, because missing a real pneumonia case is
much worse than a false alarm. So we also report \emph{sensitivity} (how many
pneumonia cases the model catches), \emph{specificity} (how many normal cases it
correctly leaves out), \emph{precision}, and the \emph{AUC}, which measures how
well the model separates the two classes overall. We also use Youden's J, a single
number that combines sensitivity and specificity ($J=\text{sensitivity}+
\text{specificity}-1$) \cite{youden1950}. For each model we choose the decision
threshold using the validation set, and then test it once on the held-out test
set, which we use only for this final step.

\subsection{Looking at the data}
After re-splitting, we have 4{,}684 training images, 585 validation images and 587
test images. The class imbalance is clear (Figure~\ref{fig:classdist}), which is
why we use the weighted sampler from Section~\ref{sec:imbalance}. Looking at sample
images (Figure~\ref{fig:samples}) we can see the orientation markers, as well as

\subsection{Hyperparameter search}
The random search (Section~\ref{sec:search}) tested 20 different settings. The
best one scored only slightly higher than our default settings on the validation

tells us the default settings were already close to the best the search could
find, so both the default and the tuned model are sensible starting points for
the main comparison.

We then ran the controlled experiment from Section~\ref{sec:locked}. Both models
were trained in exactly the same way and tested on the same images. The results

metrics (Figure~\ref{fig:comparison}, Table~\ref{tab:results}) --- are presented

\section{Findings}
\label{sec:findings}
On the test set, the model trained on the original images reached a Youden's J of
$0.8992$ (sensitivity $0.9369$, specificity $0.9623$, accuracy $0.9438$, AUC
$0.9891$). The model trained on the cleaned images reached a Youden's J of
$0.8877$ (sensitivity $0.9065$, specificity $0.9811$, accuracy $0.9267$, AUC
$0.9878$). The differences (cleaned minus original) are: $-0.0115$ in Youden's J,
$-0.0304$ in sensitivity, $+0.0189$ in specificity, $-0.0170$ in accuracy and
$-0.0013$ in AUC (Table~\ref{tab:results}).

The two changes point in opposite directions. The cleaned model has fewer false
positives ($6\!\rightarrow\!3$, so higher specificity), but more false negatives
($27\!\rightarrow\!40$, so lower sensitivity), as shown in the confusion matrices
(Figure~\ref{fig:confusion}). The drop in sensitivity is the larger of the two,
which is why the combined measures (Youden's J, accuracy and AUC) all end up
slightly lower for the cleaned dataset.

\section{Conclusion}
\label{sec:conclusion}
Coming back to \textbf{Q1} (Section~\ref{sec:rq}): for this dataset and this
model, removing the markings did \emph{not} improve pneumonia classification.
Cleaning produced a trade-off rather than a clear gain. It made the model a little
more cautious --- fewer normal images were wrongly flagged as pneumonia (higher
specificity) --- but it also caused more real pneumonia cases to be missed (lower
sensitivity). Because missing a real case is the more serious mistake here, this
trade-off is unfavourable, and the combined measures (Youden's J, accuracy and
AUC) all came out slightly lower for the cleaned dataset
(Table~\ref{tab:results}, Section~\ref{sec:findings}). So we found no sign that
removing the markers helps; the model's decisions seem to be driven by the lungs,
not the printed text. In other words, the shortcut we were worried about
\cite{geirhos2020shortcut,degrave2021shortcut} does not appear to be helping the
model here, probably because the weighted sampler, the augmentation, and the fact
that the markers sit outside the lungs already limit their effect.

For the supporting questions: the OpenCV-and-inpainting method (Q1.1) removed the
markings reliably and cheaply without harming the lungs
(Figure~\ref{fig:cleaning}), and the weighted sampler (Q1.2) kept the comparison
fair by handling the class imbalance.

This study has some limitations. We tested only one CNN, on one split of one
dataset of children's X-rays, and our cleaning only removes bright markings near
the edges rather than cutting out the lungs completely, so some non-lung content
may remain. A negative result on one split is also not full proof that there is no
effect. Future work could (i) repeat the experiment with several random splits and
report a range of results, (ii) use a lung-segmentation model (such as U-Net) so
the model only sees the lung area, and (iii) use Grad-CAM heatmaps to show
directly where the model is looking. That would add visual evidence to support the
result we found here.
